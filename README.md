# ecommerce-customer-intelligence
End-to-end data science project for e-commerce customer intelligence, delivery analytics and machine learning.
## Data Quality

An automated data quality pipeline was created in:

`src/data_quality.py`

The pipeline checks:

- row counts
- column counts
- duplicate records
- missing values
- missing value percentages
- memory usage

Detailed findings are documented in:

`reports/data_quality_report.md`
